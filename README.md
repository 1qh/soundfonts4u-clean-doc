# soundfonts4u-clean-doc

Decision records and runbooks for `soundfonts4u-clean`: a deterministic rebuild of the soundfonts4u SF2 collection into flat, deduplicated, family fonts with unique short names.

## Map

- [GOAL](GOAL.md) — what the output must be and how it is judged.
- [DONE](DONE.md) — the definition of done, each requirement with its proof, and the proven facts.
- [STATUS](STATUS.md) — owed work in order.
- [adr/pipeline](adr/pipeline.md) — stages from pinned upstream to written fonts.
- [adr/dedupe](adr/dedupe.md) — what counts as the same sound.
- [adr/families](adr/families.md) — family labelling, splitting, ordering.
- [adr/naming](adr/naming.md) — preset and font name rules.
- [adr/stack](adr/stack.md) — runtime, gate, dependencies with rejection rationale.
- [adr/exclusions](adr/exclusions.md) — upstream files left out and why.
